# Boda Emanuel & Lidia — Proyecto Angular 19+

Landing page editorial de boda andaluza desarrollada en **Angular 19** con componentes Standalone, Signals, Web Audio API y Tailwind CSS.

## 🚀 Pasos para ejecutar:

1. **Descomprimir el archivo ZIP:**
   ```bash
   unzip boda-emanuel-lidia-angular.zip
   cd boda-emanuel-lidia
   ```

2. **Instalar dependencias de Node.js:**
   ```bash
   npm install
   ```

3. **Iniciar el servidor:**
   ```bash
   npm start
   # o bien: npx ng serve
   ```

4. **Abrir en el navegador:**
   Accede a `http://localhost:4200/`
